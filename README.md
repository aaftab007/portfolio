# Aaftab Mohammad - Portfolio

Embedded Software & Firmware Engineer portfolio showcasing real-time embedded systems, automotive ECU firmware, and IoT work. Built with Next.js, TypeScript, and Tailwind CSS.

**Live site:** [aaftabmohammad.com](https://aaftabmohammad.com)

## Tech Stack

- **Frontend**: Next.js, React, TypeScript, Tailwind CSS
- **Embedded**: C, C++, Embedded C, FreeRTOS, AUTOSAR, ARM Cortex-M
- **Protocols**: CAN, SPI, I2C, UART, BLE, Wi-Fi, LoRaWAN
- **Tools**: Git, Jenkins, JTAG, AWS IoT, Azure IoT Hub

## Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/aaftab007/portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**  
   Navigate to [http://localhost:3000](http://localhost:3000)

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run start` - Start production server
- `npm run lint` - Run ESLint
